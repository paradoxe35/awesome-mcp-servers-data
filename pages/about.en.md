# About Awesome MCP Servers

Awesome MCP Servers is a curated, continuously updated directory of [Model Context Protocol](https://modelcontextprotocol.io) servers — the connectors that let AI assistants and agents read data, call tools and take actions in external systems.

## What you'll find here

- **MCP servers by domain** — cloud and DevOps, databases and messaging, code execution and automation, data access and integration, file management, business and commerce, blockchain, monitoring and more.
- **Middleware and orchestration** — gateways, routers and frameworks for running and composing servers.
- **Development tools and resources** — SDKs, testing and debugging tools, documentation and learning material.

## How the directory is maintained

The directory is built and maintained with the [Ever Works](https://ever.works) platform. AI agents research new servers, keep existing listings current and organize everything into categories and tags; every listing links back to its source repository or website.

Building an MCP server that isn't listed yet? Use the **Submit** page to add it.
